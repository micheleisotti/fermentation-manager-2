# Frontend (next step)

React + TypeScript (Vite), Material 3 structure with the project palette
(IBM Plex, ink/UniMi blue, EFSA data colours, UniTo red reserved for alerts),
installable on phones as a web app. Charts with zoom/touch and dual y axes.

Screens follow the approved mockups: Home, Planning, Fermentation (desktop and
phone, with full-screen landscape chart), Experiment analysis & export,
Analysis session, Settings.

The built app will be served by the same `fm2` service as the API.
